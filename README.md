# Life OS

Личный адаптивный планировщик жизни: план дня и недели вокруг рабочего блока 09:00–18:00, кнопка «Нужно поработать» с предпросмотром перестройки, еда, сон, шаги, вес, тренировки, покупки, напоминания (в приложении, Telegram, push), вечерний и недельный обзор с наградами. Веб и PWA для iPhone и Mac, одна база данных.

Требования — `LifeOS_PRD_v1.0_RU.md`. Архитектурные решения и компромиссы — `DECISIONS.md`. Правила кода — `CLAUDE.md`.

**Стек:** Next.js 16 (App Router), React 19, TypeScript strict, Tailwind 4, PostgreSQL 15+ (RLS), postgres.js, zod, Luxon, sharp, web-push, Vitest, Playwright. Без Supabase и платных сервисов; ИИ подключается по желанию через OpenAI-совместимый API (OpenAI, Ollama, whisper-сервер).

## Быстрый старт (локально, macOS)

Нужны Node 20.9+ (22 рекомендуется), pnpm 10, PostgreSQL 15+.

```bash
pnpm install
cp .env.example .env.local        # заполни DATABASE_URL, TEST_DATABASE_URL, секреты
pnpm db:create-local              # создаст базы из DATABASE_URL и TEST_DATABASE_URL
pnpm db:migrate                   # применит db/migrations/*.sql
pnpm user:create you@example.com  # пароль спросит (или LIFEOS_PASSWORD=...)
pnpm dev                          # http://localhost:3000
pnpm worker                       # во втором терминале: напоминания и развёртывание плана
```

Минимальный `.env.local` для разработки:

```dotenv
DATABASE_URL=postgres://<user>@localhost:5432/lifeos_dev
TEST_DATABASE_URL=postgres://<user>@localhost:5432/lifeos_test
APP_URL=http://localhost:3000
SIGNUP_MODE=open                  # форма регистрации на /login — только для разработки
MEDIA_SIGNING_SECRET=<openssl rand -hex 32>
CRON_SECRET=<openssl rand -hex 32>
```

После входа открывается первая настройка: рабочие дни и часы, сколько нужно на утро (подъём вычисляется, а не навязывается), окна еды, тренировки, свои проекты, пробные привычки. Затем — предпросмотр «Вот твой базовый распорядок».

Демо-данные (отдельный тестовый аккаунт, прошлая неделя проигрывается через настоящие сервисы): `pnpm seed:demo` → `demo@lifeos.local` / `demo-password-123`.

## Интеграции (все необязательны)

Без ключей приложение полностью работает в ручном режиме, а в «Настройки → О приложении → Подключения сервера» честно написано «не настроено» (без имён переменных и команд — они только здесь).

- **Telegram (бесплатно).** Создай бота у @BotFather → `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`. Локально — `pnpm bot:poll`. На сервере — `TELEGRAM_WEBHOOK_SECRET` + `pnpm bot:webhook set`. В вебе: «Настройки → Telegram → Подключить» (одноразовая ссылка `/start <код>` на 10 минут).
- **Push (бесплатно).** `pnpm vapid` → `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`. На iPhone push работает только из PWA, добавленной на экран «Домой» (iOS 16.4+).
- **Голос бесплатно на сервере.** В `docker-compose.yml` есть необязательный сервис `whisper` (faster-whisper на CPU, OpenAI-совместимый API, лимит 1,5 ГБ RAM / 2 CPU):
  1. `docker compose --profile voice up -d whisper`.
  2. В `.env` указать `AI_TRANSCRIBE_BASE_URL=http://whisper:8000/v1` и `AI_TRANSCRIBE_MODEL=Systran/faster-whisper-small`.
  3. Один раз скачать модель (команда — в комментарии в compose).
  4. В «Настройки → Приватность» включить «Распознавать голос».

  ⚠️ Образ сторонний и на сервере ещё не запускался.
- **ИИ.** Любой OpenAI-совместимый сервер:
  - OpenAI: `AI_LLM_API_KEY`, `AI_LLM_MODEL`, `AI_VISION_MODEL`, `AI_TRANSCRIBE_API_KEY`.
  - Локальная Ollama: `AI_LLM_BASE_URL=http://localhost:11434/v1`, `AI_LLM_MODEL=gemma4:12b`, `AI_VISION_MODEL=qwen3-vl:4b-instruct`.
  - Голос: whisper-сервер с маршрутом `/v1/audio/transcriptions` (`AI_TRANSCRIBE_BASE_URL`).

  Отправка во внешний ИИ включается отдельными согласиями в настройках; есть дневной лимит `AI_DAILY_REQUEST_LIMIT`.

## Продакшен (Docker, сервер netcup, `life.astudypro.com`)

1. DNS: в Cloudflare добавить `A life → 159.195.159.164` (как у `app.astudypro.com`).
2. На сервере: `/opt/life-os/.env` из `.env.example`. Обязательно: `POSTGRES_PASSWORD`, `APP_URL=https://life.astudypro.com`, `MEDIA_SIGNING_SECRET`, `CRON_SECRET`, `SIGNUP_MODE=closed`.
3. С Mac: `./deploy/deploy.sh` — проверки, rsync, `docker compose build && up -d`. Миграции применяются сервисом `migrate` перед стартом.
4. Caddy: добавить блок из `deploy/Caddyfile.snippet` в `/opt/caddy/Caddyfile` и выполнить `docker exec caddy caddy reload --config /etc/caddy/Caddyfile`.
5. Аккаунт: `docker compose exec app pnpm user:create you@example.com`.
6. Бэкап: cron `20 3 * * * cd /opt/life-os && ./deploy/backup.sh` (14 дней).

Состав стека: `db` (свой Postgres, отдельный том), `migrate`, `app` (сеть `web` для Caddy), `worker`, опционально `bot` (`--profile polling`). Лимиты памяти: 384 / 640 / 320 МБ.

## Как проверить «реальный первый день» (PRD §21.7)

1. **Вход.** `/login` → войти (или `SIGNUP_MODE=open` → «Создать аккаунт»). В первой настройке выбрать Europe/Lisbon, 09:00–18:00, время на утро, зал 21–22. На последнем шаге проверить распорядок.
2. **Дела.** «+» → `страховка, записаться на чистку зубов, написать ипотечному брокеру, купить бананы` → «Разобрать» → «Создать всё». Свой проект: «Дела» → «+ Проект».
3. **План на завтра.** «Сегодня» → «Завершить день и план на завтра» → «Принять план». Открыть на iPhone или в DevTools на 390 px.
4. **Еда и замеры.** «Здоровье»: отметить завтрак и обед («Отметить» → «Съел всё»), ввести вес 53.2 и шаги. Фото — «Здоровье» → «Фото».
5. **Переработка.** «План» → «Нужно поработать» → «+2 ч». Проверить предпросмотр → «Подтвердить» → в истории «Отменить».
6. **Тренировка.** «Тренировки» → «Начать тренировку» → подходы → «Завершить». Счётчик «x из 2» увеличится.
7. **Покупки.** «Покупки» → добавить «молоко 2 л» → отметить купленное → «Скопировать списком».
8. **Недельный обзор.** «Ещё» → «Обзор недели» → «Собрать обзор». Цифры сверяются с `/api/export`. Применить одно предложение и посмотреть diff.
9. **Telegram.** Без токена: «Настройки → Уведомления» и «О приложении» показывают «Telegram не настроен на сервере», переключатель канала неактивен (подсказок с переменными окружения в интерфейсе нет — они в разделе «Интеграции» этого README). С токеном: `pnpm bot:poll` → «Настройки → Telegram → Подключить».
10. **Права двух пользователей.** Создать второй аккаунт и попробовать открыть чужую задачу или фото — получится 404/403 (это же покрыто тестами SEC-01/SEC-03).
